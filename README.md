# TaşıtPOS Website

Oto galerilere özel sanal POS, taksitli tahsilat ve ödeme operasyonu için hazırlanmış multipage Next.js sitesi.

## Sayfalar

- Ana Sayfa: `/`
- Hakkımızda: `/hakkimizda`
- Hizmetlerimiz: `/hizmetlerimiz`
- Referanslar: `/referanslar`
- İletişim: `/iletisim`

## Çalıştırma

```bash
npm run dev
```

Production build:

```bash
npm run build
```
